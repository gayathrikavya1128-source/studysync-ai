# 📚 StudySync AI

An AI-powered study planner that helps students create personalized study schedules based on subjects, exam dates, study hours, and learning priorities.

## 🚀 Features

* Personalized study schedule generation
* Priority-based subject allocation
* Exam countdown tracker
* Difficulty-based study hour adjustment
* Study progress tracking
* AI-powered study recommendations
* Study hours visualization chart
* Exam readiness analytics
* Download study plan as CSV

## 🛠 Tech Stack

* Python
* Streamlit
* Pandas

## 📦 Installation

1. Clone the repository

```bash
git clone https://github.com/gayathrikavya1128-source/studysync-ai.git
```

2. Navigate to the project folder

```bash
cd studysync-ai
```

3. Install dependencies

```bash
pip install streamlit pandas
```

4. Run the application

```bash
streamlit run app.py
```

## 🎯 Project Goal

StudySync AI aims to help students plan their studies efficiently by generating structured schedules and providing smart recommendations based on available preparation time and exam deadlines.
